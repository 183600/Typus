# Debug Files Archive

这个目录包含了项目的调试和测试文件，已从根目录移动到这里以减少内存消耗和保持项目结构整洁。

## 文件说明

这些debug文件主要用于：
- 调试特定的编译器功能
- 测试边界情况
- 验证算法正确性
- 性能分析

## 使用方法

如果需要运行特定的debug文件，可以使用以下命令：

```bash
# 运行单个debug文件
cd debug_archive
runhaskell debug_filename.hs

# 或者编译后运行
ghc debug_filename.hs
./debug_filename
```

## 内存优化说明

将这些文件移动到单独的目录有以下好处：
1. 减少根目录的文件数量，降低内存消耗
2. 保持项目结构整洁
3. 避免这些调试文件意外地被包含在构建过程中
4. 便于管理和维护

## 注意事项

- 这些文件主要用于开发和调试，不应在生产环境中使用
- 某些debug文件可能有特定的依赖关系
- 建议在完成调试后将相关的修复整合到主要的测试套件中

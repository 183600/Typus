typus - A Go extension with ownership and dependent types

Usage: typus (COMMAND | (-v|--version))

  Typus compiler and toolchain

Available options:
  -v,--version             Show version information
  -h,--help                Show this help text

Available commands:
  convert                  Convert Typus files to Go
  check                    Check Typus syntax
  build                    Build a Typus project (calls go build)
  run                      Run a Typus project (calls go run)
  debug                    Enter debug mode
